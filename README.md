# ☕ Coffee Shop Sales Dashboard

An interactive sales analysis dashboard built in Power BI using data from a fictional coffee shop. This project highlights how data storytelling and visual analytics can help uncover trends in sales performance, product popularity, customer behavior, and store location insights.

![Dashboard Screenshot](Dashboard%20Screenshot.png)

---

## 📌 Project Objective

The objective of this dashboard is to help stakeholders analyze:
- Total sales, orders, and quantity sold over time
- Day/hour sales trends and performance by store location
- Best-performing product categories and items
- Month-over-month performance comparisons

---

## 🧩 Key Features

- **Calendar Heatmap:** Interactive monthly view showing daily sales performance
- **KPI Tracking:** Total sales, orders, and quantity with MoM change indicators
- **Category & Product Breakdown:** Analysis of top product lines and SKUs
- **Weekend vs Weekday Insights:** Comparative breakdown of shopping patterns
- **Location Analysis:** Sales comparisons between coffee shop branches
- **Hourly Heatmap:** Sales trends by day of the week and time of day

---

## 🧠 Insights Derived

- **Total Sales in May 2023:** $157K, a 31.8% increase over last month  
- **Top-selling Items:** Barista Espresso and Brewed Chai Tea  
- **Peak Sales Hours:** 8 AM–11 AM across weekdays  
- **Best-performing Locations:** Hell's Kitchen and Astoria  
- **Weekend vs Weekday Sales:** 25% of sales happen on weekends

---

## 🧾 How It Was Built

1. Cleaned raw Excel data
2. Queried key KPIs using MySQL to calculate MoM metrics
3. Imported and modeled data in Power BI
4. Built visuals including calendar heatmaps, pie charts, bar charts, and matrix heatmaps
5. Added interactivity using slicers and tooltips
